## 🚀 About Rang AI

Rang AI is an AI-powered Android application designed to enhance photos with a single tap.

The goal is to provide a fast, modern, and intelligent image editing experience using the latest AI models and Android technologies.

Whether it's improving image quality, restoring details, or enhancing visual appeal, Rang AI aims to make professional photo enhancement accessible to everyone.
